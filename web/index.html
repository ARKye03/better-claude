better-claude

Small plugins and mods that make your life (and Claude) better. by @midudev.

Install


      

        
        Paste it into Claude Code and it installs them for you.
      

    


    
    
      
  1. 
        
    After
    /after
    
        
    A prompt queue. Keep typing while Claude works: /after <task> runs it when the current task is done, without steering it.
    
        
    ❯ /after update the README
    
        
    ❯ /plugin install after@better-claude
    
        
    Source · Docs
    
      
    2. 

      
  2. 
        
    Use Haiku
    prefix _
    
        
    Start a prompt with _ and that turn runs on Haiku. Other prompts keep the session's model.
    
        
    ❯ _summarize the last commit
    
        
    ❯ /plugin install use-haiku@better-claude
    
        
    Source · Docs
    
      
    3. 

      
  3. 
        
    Think Hard
    prefix +
    
        
    Start a prompt with + and that turn thinks at max effort. Other prompts keep the session's effort.
    
        
    ❯ +plan the refactor of the parser
    
        
    ❯ /plugin install think-hard@better-claude
    
        
    Source · Docs
    
      
    4. 

      
  4. 
        
    Token Meter
    status line
    
        
    After each turn, the status line shows its tokens and the session's running total.
    
        
    ↑ 1.2k  ↓ 340  cache 4.1k  ·  session ↑ 1.2k  ↓ 340
    
        
    ❯ /plugin install token-meter@better-claude
    
        
    Source · Docs
