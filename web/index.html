better-claude

Small plugins and mods that make your life (and Claude) better. by @midudev.

Paste it into Claude Code. It installs the ones you picked.
What it copies 

        

      

    


    
    
      
  1. 
        
    Image Preview
    hover
    source · docs
    
        
    
          
    Hover a pasted [Image #1], while you write or in a prompt you sent, and the picture opens in a small window by the pointer. Click it to open it in Preview.
    
          
     hover to preview
    
          
    /plugin install image-preview@better-claude
    
        
    
      
    2. 

      
  2. 
        
    Sub Meter
    footer
    source · docs
    
        
    
          
    Your subscription usage, always at the bottom right: the 5-hour and the weekly windows take turns as a bar, with the time until each resets.
    
          
    ⏵⏵ auto mode on5h ━━━━━━──── 58% · 2h 10m
    
          
    /plugin install sub-meter@better-claude
    
        
    
      
    3. 

      
  3. 
        
    After
    /after
    source · docs
    
        
    
          
    A prompt queue. Keep typing while Claude works: /after <task> runs it when the current task is done, without steering it.
    
          
    ❯ /after update the README
    
          
    /plugin install after@better-claude
    
        
    
      
    4. 

      
  4. 
        
    Use Haiku
    prefix _
    source · docs
    
        
    
          
    Start a prompt with _ and that turn runs on Haiku, its subagents too. You see it as you type, on the spinner and under the answer. Every other prompt keeps the session's model.
    
          
    ❯ _summarize the last commit
    
          
    /plugin install use-haiku@better-claude
    
        
    
      
    5. 

      
  5. 
        
    Think Hard
    prefix +
    source · docs
    
        
    
          
    Start a prompt with + and that turn thinks at max effort. Every other prompt keeps the session's effort.
    
          
    ❯ +plan the refactor of the parser
    
          
    /plugin install think-hard@better-claude
    
        
    
      
    6. 

      
  6. 
        
    Token Meter
    hint line
    source · docs
    
        
    
          
    After each turn, the line under the prompt ends with its tokens and the session's running total, in color.
    
          
    ↑ 1.2k  ↓ 340  cache 4.1k  ·  session ↑ 1.2k  ↓ 340
    
          
    /plugin install token-meter@better-claude
